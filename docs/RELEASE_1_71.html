GrimWeaver v1.71 · Release Notes

星座等级 / Celestial ranks

在星座信息区或技能悬浮说明中调整数字框，旁边的向上双箭头可回到满级。所有63个可触发技能按经验成长表确定上限；例如暗杀者的标记为25级、治疗之雨为15级。没有触发技能的被动星座不会显示等级控制。预览未点亮技能不会投入星座点。

Edit the numeric rank in the constellation information or power tooltip. The double-up arrow restores maximum rank. All 63 powers use their experience growth tables; Assassin's Mark caps at 25 and Healing Rain at 15. Passive constellations have no growth-rank control. Previewing an unallocated power does not spend devotion points.

等级变化同步用于星座说明、增益、召唤物和当前构筑对敌削弱。查询工具的手动等级仍是独立的对比场景，不会偷偷改动构筑。schemaVersion=1和DB1编码保持不变。

Rank changes update tooltips, buffs, summons and current-build debuffs. Manual research-tool ranks remain separate comparison scenarios and do not modify the build. Schema v1 and DB1 remain unchanged.

语言记忆 / Language persistence

沿用本机地址http://127.0.0.1:15688/。最近选择的中英文写入当前Windows用户的%LOCALAPPDATA%\GrimWeaver\preferences.json，同时保留浏览器缓存。启动时优先读取该配置，即使浏览器缓存不同也能恢复。配置只含语言，不含角色、构筑或私人文件路径；不会上传网络。配置不可写时仍尝试浏览器本地记忆。

The local address remains http://127.0.0.1:15688/. The latest language is stored in the current Windows user's %LOCALAPPDATA%\GrimWeaver\preferences.json with a browser cache fallback. Launch restores this setting even with a different browser cache. The file contains only language, not characters, builds or private file paths; nothing is uploaded.

兼容、源码和范围 / Compatibility, source and scope

不修改游戏数据库、角色存档或旧版发布包。保留既有双语版权说明和Rem用途授权。源码包中可直接修改界面；用.NET 8 SDK执行tools/build-launcher.ps1重建启动器。以随包数据为基础更新等级查询数据时执行node tools/update-data-v171.cjs。正式应用包不含核查报告、测试图片、私人存档或偏好配置。

Game databases, character saves and previous release archives are unchanged. Existing bilingual notices and Rem permission are retained. Rebuild the launcher with .NET 8 SDK and tools/build-launcher.ps1. Refresh celestial rank research data from the bundled packs with node tools/update-data-v171.cjs. Release archives exclude audit reports, screenshots, private saves and personal preferences.

本版本修复等级选择与默认行为，不代表所有数值已与游戏引擎完全一致。原有静态伤害、随机变量和敌人状态的范围限制继续适用。

This fixes rank selection and defaults, not full game-engine parity. Existing limits for static damage, random item rolls and enemy states still apply.
