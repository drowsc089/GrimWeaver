GrimWeaver v1.7 · Release Notes

降抗 / Resistance reduction

已按42专精、1,409个技能节点及各自正常/超限等级重新遍历。敌方进阶节点共15个，自身抗性惩罚不归入对敌降抗。“惊魂余音”普通上限12、超限上限22：物理和元素降抗分别为25%/35%，流血为40%/50%。自动触发与战宠关联效果使用各自等级。“所有抗性”新字段另行识别。不同物品变体引用相同效果时只取最高一次。

All 42 masteries and 1,409 skill nodes were re-traversed through supported ranks. Fifteen hostile modifier nodes are distinguished from self penalties. Falter caps at 12/22, reducing physical/elemental resistance by 25%/35% and bleeding resistance by 40%/50%. Linked pet/proc effects retain their own ranks. The newer all-resistance field is recognized. Identical effect records across item variants apply once, at the strongest selected value.

手动查询可加入物品技能修正；它们须作用于对应技能，套装须达到件数条件。手选来源不自动验证整套装备是否合法。当前构筑载入仍遵循穿戴与套装解锁条件。条件触发不等于常驻覆盖率。

Manually selected item modifiers require the modified skill and applicable set threshold. Manual scenarios do not validate equipment legality. Loading current-build sources respects equipped gear and active set thresholds. Conditional effects are not permanent uptime.

敌人分类 / Enemy categories

新增普通、精锐、精英、首领、复仇、超级首领；内容来源按记录首次出现的本体/AoM/FG/FoA/GAL归类，GAL覆盖另行标注。新增主线世界、碎裂之境、永恒之境场景。碎裂变体完整标为“[碎裂之境]”。不把模组不可进入的Crucible作为可玩分类。

Types: Common, Champion, Hero, Boss, Nemesis and Superboss. Content source uses the layer that introduced the record; later GAL overrides are separately marked. Encounter filters distinguish Campaign, Shattered Realm and Eternal. Shattered variants use the full encounter name. Crucible is not offered as a playable GAL mode.

永恒之境既有独立敌人记录，也会引用主线敌人。按本机_eternal.arc脚本与有效波次/代理引用图建立分类，不按名称猜测。脚本/名册引用不保证每只敌人在每一波都出现。五档额外永恒升阶与游戏飞升难度完全独立；目前通用升阶对列出的十类伤害抗性均为+0，不代表生命、伤害和攻防能力相同。独立敌人自身的抗性仍按各自GAL记录展示，不能统一视为主线同值。

Eternal uses both dedicated records and shared campaign enemies. Categorization follows local archive scripts and the active wave/proxy reference graph, not name matching. Registry references do not guarantee every enemy spawns in every wave. Its five extra Ascension stages are separate from the native Ascendant difficulty: their general adjustment adds +0 to the ten listed damage resistances, while other stats change. Dedicated monsters retain their own effective GAL resistance values.

基础抗性统计不包含随机装备、临时增益、祭坛供奉、碎裂层数与随机变异。不能把表中数值理解为全部战斗状态。 / Base resistance statistics exclude random gear, temporary buffs, offerings, shard scaling and mutators; they are not all-state combat values.

物品技能与颜色 / Item skills and colors

读取授予/触发技能及其关联增益、投射物、召唤物技能的原始说明；展示可识别的作用目标、范围、持续、消耗、召唤上限、触发条件和基础/人物加成后固定伤害。去掉父子递归造成的重复效果。未提供的说明不自行编写；原始关联缺失时明确提示。“催化风暴”的原始元素抗性字段为正25，按原值显示，不擅改为负数。

Descriptions are read from linked granted/proc skills, buffs, projectiles and summon skills. Recognized targets, radius, duration, costs, summon caps, triggers and base/scaled flat damage are shown without recursive duplication. Missing source descriptions are not invented. Catalyst Storm's source elemental-resistance value is positive 25 and is not silently changed into RR.

伤害仍是静态固定伤害估算，未完整计算武器伤害、反击附加、敌人减伤、暴击、特殊机制与覆盖率。名称采用当前中英文文本的白名单颜色标签，未标色才按稀有度回退；明亮主题使用可读的对应深色。普通品质不再默认金色。

Damage remains a static flat-damage estimate, excluding full weapon-damage, added retaliation, enemy mitigation, crits, special mechanics and uptime. Whitelisted localization colors take precedence over rarity defaults, with readable light-theme equivalents. Untagged common items no longer default to gold.

兼容与源码 / Compatibility and source

不改角色存档或游戏数据。保持schemaVersion=1、DB1格式及未知扩展字段，新增v1.6兼容样本。新端口15688；空闲旧端口15681–15687保留跳转。旧应用占用端口时，可将完整旧链接粘贴到新版分享码框。源码包的数据更新脚本build-data-v17.cjs以附带数据包为基础，使用GRIMWEAVER_DATABASE_CACHE、GRIMWEAVER_LOCALIZATION_ROOT、GRIMWEAVER_VANILLA_ZH与DAWNBUILD_GAME指向本地五层数据库缓存、双语文本与游戏目录；它不是从零生成全部美术资源的工具。

Game data and saves are not modified. Schema v1, DB1 and unknown extension fields are retained, including v1.6 fixtures. The new port is 15688; free legacy ports 15681–15687 redirect. If occupied by an older app, paste the complete old link into the new share-code box. The source archive includes an incremental data-refresh script using the bundled packs plus the local five-layer database cache, localization and game directories configured through environment variables. It is not a from-scratch artwork exporter.

现有Rem用途授权、中英版权声明、第三方归属继续保留；本版本不新增外部美术素材。正式包不含私人存档、核查报告或测试截图。

Existing Rem permission records, bilingual notices and third-party ownership remain unchanged. No new external artwork is added. Distributable archives exclude private saves, audit reports and test screenshots.
